## 실험을 통한 교훈

### Do's ✅
1. **반드시 전체 샘플 테스트** - 부분 테스트는 위험
2. **구두점 영향 테스트** - 마침표, 쉼표가 성능에 영향
3. **언어 일관성 유지** - 한국 데이터는 한국어로
4. **단순명료한 조건문** - "A면 1, 아니면 0" 구조

### Don'ts ❌
1. **테스트 없는 제출** - 치명적 실수 가능
2. **특수문자 사용** - `=`, `:` 등은 파싱 오류
3. **주관적 기준** - "핵심이면", "중요하면" 등
4. **과도한 복잡성** - CoT가 항상 좋은 것은 아님
