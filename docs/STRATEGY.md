- **평가 모델**: GPT-4o-mini (temperature=0.4)
- **점수 공식**: `S = 0.9 × Accuracy + 0.1 × √(1-(bytes/3000)²)`
- **제약**: 프롬프트만 제출 (코드 X, 모델 변경 X)

### 점수 공식 분석
```

여기서:

```

## 3. 프롬프트 엔지니어링 전략

### 3.1 기본 전략
1. **단순명료**: 복잡한 조건보다 간단한 표현
2. **키워드 중심**: "자동차"라는 명확한 키워드 사용
3. **조건문 구조**: "A면 1, 아니면 0" 형식

### 3.2 발견한 패턴

#### 성공 패턴
- `자동차 아니면 0 맞으면 1` (100% 정확도)
- 구두점 제거 시 성능 향상
- 한국어 > 영어 (6.5% 차이)

#### 실패 패턴
- `자동차 1` (10.9% 정확도) - 조건문 없음
- 특수문자 사용 (`=`, `:`등) - 파싱 오류
- 주관적 기준 ("핵심이면", "중요하면")

### 3.3 Chain of Thought (CoT) 분석
- 단순 이진 분류에서는 효과 제한적
- 길이 페널티로 인한 점수 하락
- "주제를 분석한 후 답하세요" 형식이 가장 효과적
